New Docker images for `Yolo26 <https://github.com/ultralytics/ultralytics/>`__ are now available, which now
offer support for slicing via the `sahi <https://github.com/obss/sahi>`__ library.

The code used by the docker images is available from here:

`github.com/waikato-datamining/pytorch/tree/master/yolo26 <https://github.com/waikato-datamining/pytorch/tree/master/yolo26>`__

The tags for the images are as follows:

* Docker hub:

  * ``waikatodatamining/pytorch-yolo26:8.4.16_cuda12.6-2``
  * ``waikatodatamining/pytorch-yolo26:8.4.16_cpu-2``
